Changelog

Every release of the Mikaju Payroll desktop app, tracked here. Installers are built automatically from source on every release.

Full build history: github.com/MonarCat/mikaju-payroll/releases
v1.0.2Fix

Release pipeline & legacy build stability

  • Stabilized the dual-track release pipeline covering modern Electron (Windows 10+, macOS, Linux) and legacy Electron builds for Windows 7/8
  • Verified all installer download links across every supported platform
v1.0.1Improved

Core renderer screens

  • Shipped Login, Signup, and guided Onboarding flows
  • Employee management screen with country-aware required fields
  • Payroll Run Wizard for period selection, calculation, review, and approval
v1.0.0New

Initial release

  • Offline-first payroll engine covering all 9 East and Central African countries
  • Full statutory tax engine for Kenya, Uganda, Tanzania, Rwanda, and Ethiopia
  • Core income tax and social contribution engine for Burundi, South Sudan, Somalia, and DR Congo
  • PDF payslip generation and P9A / annual tax certificate generation
  • Encrypted local database with cloud sync and backup
Versioning.Mikaju follows semantic versioning (major.minor.patch). Statutory rate updates that don't change app behavior are tracked separately on the Tax Updates page and ship through the same auto-update channel.
